# CV Index

When a new JD comes in, start with this table to find your starting point. Fill it in, then update it after every version you make.

**How to use it**: ① Decide which type the JD belongs to → ② compare its requirements against each type's "core skill sets" and pick the closest version → ③ if the industry differs, check "lead experience" to decide what to swap → ④ copy that version and edit from there.

## Status and freezing

| Status | Meaning |
|---|---|
| Draft | A draft the user hasn't reviewed |
| Approved | The user approved it; it can be used as a baseline |
| Sent | Submitted to an employer; **frozen**, never edited |
| Unused | Made but not sent |
