# PROMPTS · 可直接复制的提示词

在对应的时刻把它们贴给 AI。方括号里的内容换成你自己的。

## 0. 第一次使用

```text
先读 AGENTS.md，再读 docs/WORKFLOW.md。我第一次用这套工具，带我一步一步做 Step 0。每一步开始前，先告诉我这一步要产出什么、需要我提供什么。我说继续之前，不要进下一步。
```

## 1. 导入我现有的简历（Step 0）

```text
先读 AGENTS.md 和 docs/WORKFLOW.md（Step 0）。这是我现在的简历：

[把简历贴在这里]

先不要写任何 Claim Card。把你能找到的每一项成果列成编号清单，每项一行。凡是含糊的、没有数字的，都标出来。然后等我回复。
```

## 2. 采访我，写一张 Claim Card（Step 0）

```text
先读 evidence/claims/_TEMPLATE.md。就你清单里的第 [N] 项成果采访我，一次只问一个问题。要问清楚：
- 背景
- 我本人做了什么，团队做了什么
- 每个数字量的是什么（单位、时间窗口、累计 / 单个 / 潜在）
- 我不能说的因果
- 我能怎么证明

不要奉承我，也不要用猜测补空白。等我说「好了」，再写出状态为 `需复核` 的 Claim Card 给我看。
```

## 3. 给某个岗位做一版

```text
按 docs/WORKFLOW.md 的 S1 到 S6，给这个岗位做一版：

[把 JD 贴在这里]

先告诉我：岗位类型、你选的基线、你读了哪些 Claim ID。只能用状态为 `Safe to draft` 的 claim。做到 S7 之前停下，给我看全文、和基线的改动对照、以及 Coverage Report。
```

## 4. 自审一版

```text
对照 docs/REVIEW-CHECKLIST.md 审一遍 cv/resumes/[文件名].md。用表格报告发现的问题，能改的直接改，没法检查的单独列出来。
```
