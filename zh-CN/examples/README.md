# examples

这里的内容**全部虚构**：人物、公司、数字都是编的。不要抄进自己的简历。

- [jordan-lee/](jordan-lee/README.md)：一套完整的小项目，结构和你自己的一样。五张 Claim Card、一份批准的基线、针对一个岗位的新版本（附 Change Log 和填好的 CV-INDEX），以及一份埋了七个错误的副本。用 `check_claims.py` 跑一遍，就能看到通过和未通过的样子，以及哪些错误只有人能发现。
- [cases.md](cases.md)：10 个改前改后的小案例，每个演示一两条规则。

`jordan-lee/reports/` 里的两份体检报告是虚构的演示数据，由 0.2.3 版工具包生成。它们只用来展示报告长什么样，不代表当前版本的评分，分数也不代表能不能拿到面试或录用。
