# CV Index

新 JD 来了，先看这张表定位起点。填好后，每做完一版就更新。

**怎么用**：① 判断 JD 属于哪个类型 → ② 用「核心 skill sets」比对 JD 要求，选最接近的一版 → ③ 行业不同时看「主打经历」决定要换哪些 → ④ 从那版复制改起。

| 状态 | 含义 |
|---|---|
| Draft | 草稿，未经本人审核 |
| Approved | 本人审核通过，可作为基线 |
| Sent | 已投递，**冻结**，不再修改 |
