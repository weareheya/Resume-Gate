# C-000 · 一句话概括成果

## 事实（原始、未经润色）
你实际做了什么，用平实的话。包括背景、你的具体动作、结果。

## 数字与口径
| 数字 | 单位 / 币种 | 时间窗口 | 口径（累计 / 单个 / 潜在 / 实际…） |
|---|---|---|---|
| | | | |

## 归因
- **本人做的**：
- **团队 / 他人做的**：
- **不能说的因果**：（同期发生但不是你带来的）

## 已批准措辞
> 一两句可直接放进简历的写法。

## 禁止改写
- 不能写成 …（因为 …）
- 不能把 A 和 B 混在一起

## 出处
证据在哪：邮件、合同、仪表盘截图、同事证言、公开链接……没有就写「仅本人陈述」。

## 备注
面试时要准备讲清楚的点。
