# C-000 · 一句话概括成果

## 事实（原始、未经润色）
你实际做了什么，用平实的话。包括背景、你的具体动作、结果。

## 数字与口径
| 数字 | 单位 / 币种 | 时间窗口 | 口径（累计 / 单个 / 潜在 / 实际…） | 核实 |
|---|---|---|---|---|
| | | | | ✓ |

「核实」一列：本人在采访里亲口说的数字直接写 `✓`。空白也按已确认处理（`validate_evidence.py` 会提醒你打勾）；写别的值，这个数字就不能用。本人说「大概」「记不清」的，或者 AI 从旧材料里摘、本人还没确认的，写 `待核实`。标着 `待核实` 的数字不能写进简历，`check_claims.py` 会报错；同一张卡上其他数字照常能用。

## 出处
证据在哪：邮件、合同、仪表盘截图、同事证言、公开链接……不需要拿得出来，能说出来源就行（「季度复盘里的数」）。什么都没有就写「仅本人陈述」，这很常见，不影响上简历。
